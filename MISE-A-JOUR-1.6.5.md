# Mise à jour Liberté Premium 1.6.5

## Navigation
- La barre inférieure garde les raccourcis Accueil, Rituels, Protocoles, Parcours tabac, Parcours alcool, Bibliothèque et Réglages, dans l’ordre du menu latéral.
- Les raccourcis des statistiques tabac et alcool ne sont plus dans la barre inférieure. Les deux pages restent accessibles dans le menu latéral.
- Le menu latéral est plus compact, avec des zones tactiles conservées.

## Données et sauvegarde
- Le bloc « Données et sauvegarde » est placé en premier dans Réglages, juste sous l’en-tête de section.

## Version
- Version applicative : 1.6.5.
- Version Android : code 2026110501.
- Cache PWA renouvelé pour forcer la mise à jour des ressources.
